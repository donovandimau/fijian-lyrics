# Fijian Lyrics Site

Simple, fast searchable site for Fijian song lyrics.

## Songs included (MVP)
- Meda Dau Doka (National Anthem)
- Isa Lei (Traditional farewell)
- Bula Maleya (Welcome song)
- Loma ni Buca (Folk)

More songs can be added to `data/songs.json`.

## Deploy
- Drop the folder into a Vercel project, or
- `npx vercel` from this directory.

## Branding
Uses FijiLearn-inspired palette (lagoon, coral, sand, ink).
